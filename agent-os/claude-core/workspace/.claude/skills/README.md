# Skills

Lege hier deine Doku-Skills ab, je Skill ein Ordner mit `SKILL.md`:

```
skills/
  dokument-generator/
    SKILL.md
    (optionale Hilfsdateien, Templates …)
```

Claude Code im `claude-core`-Container laedt diese automatisch — auch im `-p`-Modus,
sowohl auto-getriggert als auch per `/skill-name` im Prompt.
